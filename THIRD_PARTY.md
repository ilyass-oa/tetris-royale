# Third-party components

- **nlohmann/json**: the bundled single header preserves its MIT license and copyright notice. Its public upstream is https://github.com/nlohmann/json. A system package can be used instead.
- **SFML 3.0.0**: downloaded at configuration time from https://github.com/SFML/SFML. Distributed upstream under the zlib/png license; its source retains the corresponding notice. Old compiled platform SDKs are not part of this repository.
- **DejaVu Sans**: bundled with `assets/fonts/LICENSE-DejaVu.txt`. The notice includes the original Bitstream terms and DejaVu changes. Old unverified font files are excluded.
- Menu artwork is inherited from the academic project. No new reuse license is asserted for these assets or the collective game sources.

Required attribution notices for third-party libraries/fonts are retained. They are separate from personal information belonging to the former project team.
